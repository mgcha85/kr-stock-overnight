# 백테스트 미래 데이터 누수(Look-Ahead Bias) 검증 및 방지보고서

## 1. 개요
오버나이트 AI 전략의 실운용 이행(Live Handoff) 전, 백테스트 엔진 내 **미래 참조 오류(Look-Ahead Bias) 및 데이터 오염 요소**가 완전히 제거되었음을 증명하기 위한 6대 검증 체계 명세입니다.

---

## 2. 6대 미래 데이터 누수 방지 통제 항목 (Checklist)

### ① 캔들 가격 및 기술적 지표 (Price & Indicator Causal Integrity)
- **진입 가격 (`close`)**: 당일 $T$일 15:30 정규장 종가 체결. (당일 15:30 시점 확정치)
- **청산 가격 (`next_open`)**: 익일 $T+1$일 09:00 정규장 시가 체결. (익일 09:00 시초가 확정치)
- **기술적 지표 계산**: RSI, 볼린저 밴드, 5일 평균 거래대금 비율, 1/3/5일 수익률 등 모든 10가지 기술적 피처는 **$T$일 포함 과거 캔들 데이터만을 사용**하여 계산됨.

### ② 뉴스 데이터 시점 필터 (`published_at <= 15:30:00`)
- **필터링 조건**: 당일 $T$일 매수 신호 생성 시 **`published_at <= T일 15:30:00`** 인 뉴스 기사만 인덱싱.
- **통제**: 15:30:00 정규장 마감 이후(장후 시간외, 야간) 발송된 기사는 당일 신호 결정 시 절대 참조 불가.

### ③ DART 전자공시 시점 필터 (`rcept_dt == T일 & Time <= 15:30`)
- **필터링 조건**: 당일 $T$일 정규장 마감 전 접수된 공시만 보조 점수(+10~20점)로 반영.

### ④ 한국 주식 상한가(+30%) 매수 불가 필터 (`stock_change < 29.0%`)
- **제약 반영**: 당일 상한가(+29.5% ~ +30.0%)로 잔량이 굳어버린 종목은 15:30 장마감 종가 매수가 불가능(Ask Volume = 0)하므로 **체결 불가로 간주하여 백테스트 대상에서 100% 제외**.
- **스위트 스팟**: `+15.0% <= stock_change < 29.0%` 구간의 상한가 직전 고가 마감 종목만 15:30 종가 매수 체결.

### ⑤ ML/DL 모델 데이터 분리 (Walk-Forward Train/Test Isolation)
- **In-Sample 학습**: 2026년 5월 데이터로만 LightGBM 및 PyTorch 모델 학습.
- **Out-of-Sample 검증**: 2026년 6월 미지의 데이터에 대해 학습된 모델 weights로 순수 추론(Inference) 수행. (data leakage 0%)

### ⑥ 슬리피지 및 세금/수수료 반영 (Real-world Friction)
- **수수료 및 세금**: 매매 수수료 + 증권거래세 **0.23%** 정률 차감 적용.
