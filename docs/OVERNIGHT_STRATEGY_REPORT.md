# 한국 주식 Overnight (종가 베팅) 전략 리서치 및 데이터 가공/수익화 계획서

---

## 1. 한국 주식 시장 Overnight (종가 베팅) 전략 개요 및 수익 원리

### 1.1 Overnight (종가 베팅)이란?
당일 장 마감 직전(**15시 15분 ~ 15시 30분 동시호가**)에 시장의 **주도 테마, 거래대금 상위주, 강한 뉴스/DART 공시 종목, 세력의 수급주**를 매수하여, **다음 날 개장 직후(09시 00분 ~ 09시 10분)** 갭상승(Gap-up)을 활용해 매도하여 수익을 확정 짓는 단기 알파(Alpha) 매매 전략입니다.

### 1.2 수익이 발생하는 4대 핵심 구조
1. **유동성 및 주목도 쏠림 (Attention Alpha)**: 당일 거래대금이 **500억~1,000억 이상** 터진 종목은 밤사이 개미, 기관, 외국인 투자자의 관심이 집중되며 익일 아침 시가에 매수세가 강하게 매입됩니다.
2. **장 마감 전/장후 공시 및 뉴스 재료 (Disclosure Effect)**: 14시~15시 30분 사이 및 장후 발표되는 DART 공시(대형 수주계약, 제3자배정 유상증자) 및 단독 뉴스는 밤새 수급을 끌어모아 갭상승을 유발합니다.
3. **주도 테마의 연속성 (Theme Continuation)**: 당일 시장을 지배한 테마의 1등주(대장주)는 하루 만에 시세가 끝나지 않고 다음 날 아침 동시호가까지 강력한 관성을 유지합니다.
4. **세력의 가격 관리 (Smart Money Price Defense)**: 장 막판(15:15~15:20) 주가가 밀리지 않고 고가권에서 지지받으며 횡보하는 것은 세력이 종가를 관리하고 있으며 익일 추가 시세를 낼 의지가 크다는 신호입니다.

## 2. MarketMosaic 데이터 결합 & 파이프라인 처리 방안

MarketMosaic에서 수집 중인 **뉴스, DART 공시, 펀다멘털, 테마, 캔들/수급** 데이터를 종합 가공하여 오버나이트 타겟 종목을 추출합니다.

```
+-----------------------------------------------------------------------------------+
|                            MarketMosaic Data Pipeline                             |
+-----------------------------------------------------------------------------------+
|  뉴스 (News)     | DART 공시       | 테마 (Themes)   | 캔들 (OHLCV)    | 펀더멘털 / 환율 |
|  Gemini 3.0-Flash| 공시 유형/규모  | 주도 테마/대장주 | 거래대금/종가고가| 관리종목/USD-KRW|
+--------+----------------+----------------+----------------+-----------------------+
         |                |                |                |
         v                v                v                v
+-----------------------------------------------------------------------------------+
|               Multi-Factor Overnight Scoring Model (Total: 100 Points)            |
+-----------------------------------------------------------------------------------+
|  1. 재료/공시 점수 (25점) : 호재 등급, 재료 신선도, 뉴스 발행 시점               |
|  2. 테마 주도력 점수 (25점) : 테마 상승률, 섹터 내 대장주 여부                   |
|  3. 기술적/수급 점수 (35점) : 거래대금 >= 500억, 종가/고가 비율, 3시 외인·기관 수급 |
|  4. 리스크 & 매크로 (15점) : 환율 안정성, 유상증자/CB 발행 여부, 투자경고 제외    |
+----------------------------------------+------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
|                    Overnight Order Engine (Go Runtime / KIS API)                  |
+-----------------------------------------------------------------------------------+
|  15:15 Score 계산 -> 15:20 종가 분할/동시호가 매수 -> 익일 09:00 시가/분할 매도   |

```

### 2.1 데이터 소스별 처리 및 가공 로직

#### ① 캔들 및 거래대금 (Candle & Volume)
* **모수(Universe) 필터**: 당일 거래대금 **>= 500억 원** (코스닥), **>= 1,000억 원** (코스피).
* **일봉 패턴**:
  * **종가 고가형 장대양봉**: (종가 - 시가) / (고가 - 저가) >= 0.85 (윗꼬리 15% 미만).
  * **전고점 돌파**: 최근 20일 고가 및 전일 고가 상방 돌파.
* **분봉(15분/5분) 14:30~15:20 지지 확인**: 14:30 이후 저점을 훼손하지 않고 고가권 횡보 유지.

#### ② 뉴스 데이터 (News via Gemini 3.0 Flash)
* **LLM 정량 평가**: Gemini 3.0 Flash를 통해 뉴스 제목과 본문 요약에서 호재 등급(1~10점) 산출.
* **키워드 추출**: `"단독"`, `"세계 최초"`, `"대기업 공급계약"`, `"정부 정책"`, `"FDA/임상3상"`, `"AI/반도체/로봇"`.
* **신선도 가중치**: 14:00~15:20 사이 최초 수신된 뉴스에 가중치 1.5배 부여.

#### ③ DART 공시 데이터 (DART Filings)
* **호재 공시 (Score +)**:
  * 단일판매·공급계약 체결 (최근 매출액 대비 **10% 이상**).
  * 제3자배정 유상증자 (대기업/유명 펀드 참여).
* **위험 공시 (즉시 제외 - Blacklist)**:
  * 주주배정 유상증자, CB/BW 발행, 감자, 배임/횡령, 영업정지, 상장폐지 사유 발생.

#### ④ Judal 테마 데이터 (Themes)
* **테마 상승폭 및 거래대금 순위**: 당일 시장 주도 테마 상위 3위 이내.
* **대장주 판별**: 테마 내 **상한가 달성 종목** 또는 **거래대금 1위 종목**을 대장주로 타겟팅 (3등 이하 소외주 제외).

#### ⑤ 펀더멘털 및 매크로 (Fundamentals & Macro)
* **기본 필터**: 관리종목, 투자경고/위험 지정, 시가총액 500억 미만 제외.
* **USD/KRW Watcher 연동**: 장 막판 환율 급등(+1.0% 이상) 시 overnight 포지션 비중 50% 감축.

## 3. 다중 요소 오버나이트 스코어링 모델 (Scoring Model)

종목별 점수를 **100점 만점**으로 계산하여 **80점 이상**인 최상위 2~3개 종목에 분산 투자를 집행합니다.

| 평가 지표 | 세부 가공 데이터 | 배점 | Pass/Fail 필터 |
| :--- | :--- | :--- | :--- |
| **1. 기술적 & 수급** | 거래대금 > 500억, 종가/고가 비율 > 85%, 15시 외인·기관 수급 | **35점** | 거래대금 < 300억 탈락 |
| **2. 테마 주도력** | 당일 주도 테마 Top 3 이내, 테마 1등 대장주/2등주 여부 | **25점** | 테마 3등주 이하 탈락 |
| **3. 재료 (뉴스/공시)**| Gemini 3.0 Flash 호재 점수, 14시 이후 공시/뉴스 신선도 | **25점** | 악재 공시 발생 시 탈락 |
| **4. 리스크 & 매크로** | 펀더멘털 안전성, 환율 변동성, 투자경고 지정 여부 | **15점** | 유상증자/CB 공시 탈락 |

### 매매 실행 규칙 (Trading Rules)
* **매수 (Entry)**: **15:15 데이터 수집 -> 15:20 최종 타겟 선정 -> 15:20~15:30 동시호가/지정가 매수**.
* **매도 (Exit)**: **익일 09:00 시가 동시호가 전량 매도** (+1% ~ +3% 갭상승 수익 확정).
* **손절 (Stop Loss)**: 익일 시가 갭하락(-2% 이하) 시 개장 즉시 손절.
