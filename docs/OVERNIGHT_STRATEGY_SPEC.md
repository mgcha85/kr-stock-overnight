# KRX (한국 주식) Overnight (종가 베팅) 전략 상세 명세서

## 1. 개요 및 원리 (Executive Summary)

### 1.1 Overnight (종가 베팅) 전략이란?
한국 주식 시장(KOSPI / KOSDAQ)의 **Overnight(종가 베팅) 전략**은 당일 장 마감 직전(15시 15분 ~ 15시 30분 동시호가)에 당일 시장의 **주도 테마/대장주/강력한 재료/외인·기관 수급주**를 매수하여, **다음 날 개장 직후(09시 00분 ~ 09시 10분)** 갭상승(Gap-up) 유동성을 활용해 매도하여 수익을 확정 짓는 단기 알파 전략입니다.

### 1.2 왜 한국 시장에서 종가 베팅이 높은 승률을 보이는가?
1. **유동성 및 주목도 집중**: 거래대금이 500억~1,000억 이상 터진 종목은 밤사이 개미/기관/외국인의 주목을 받아 익일 아침 시가에 매수세가 쏠립니다.
2. **장 마감/장후 공시 및 호재 재료 효과**: 14시~15시 30분 및 장 마감 후 나오는 DART 공시(단가/수액 대비 대형 수주, 제3자배정 유상증자, 특허 등)와 단독 뉴스는 밤새 호재로 작용하여 갭상승을 유발합니다.
3. **주도 테마의 연속성**: 당일 시장을 주도한 테마의 1등주(대장주)는 하루 만에 시세가 끝나지 않고 다음 날 아침 동시호가까지 강력한 매수세를 유지합니다.
4. **세력의 가격 관리 (Defense)**: 장 막판(15:15~15:20) 고가권에서 밀리지 않고 횡보하며 가격을 지켜주는 주가는 주포/세력의 익일 추가 상승 의지를 반영합니다.

## 2. MarketMosaic 다중 데이터 소스 가공 및 특징 추출 (Data Processing Pipeline)

MarketMosaic 데이터 파이프라인은 **뉴스, DART 공시, 펀더멘털, 테마, 캔들/수급 데이터**를 실시간으로 결합하여 점수화(Scoring)합니다.

```
+-----------------------------------------------------------------------------------+
|                            MarketMosaic Data Pipeline                             |
+-----------------------------------------------------------------------------------+
|  뉴스 (News)     | DART 공시       | 테마 (Themes)   | 캔들 (OHLCV)    | 펀더멘털 / 환율 |
|  Gemini 3.0-Flash| 공시 유형/규모  | 주도 테마/대장주 | 거래대금/종가고가| 관리종목/USD-KRW|
+--------+----------------+----------------+----------------+-----------------------+
         |                |                |                |
         v                v                v                v
+-----------------------------------------------------------------------------------+
|               Multi-Factor Overnight Scoring Model (Total: 100 Points)            |
+-----------------------------------------------------------------------------------+
|  1. 재료/공시 점수 (25점) : 호재 등급, 재료 신선도, 뉴스 발행 시점               |
|  2. 테마 주도력 점수 (25점) : 테마 상승률, 섹터 내 대장주 여부                   |
|  3. 기술적/수급 점수 (35점) : 거래대금 >= 500억, 종가/고가 비율, 3시 외인·기관 수급 |
|  4. 리스크 & 매크로 (15점) : 환율 안정성, 유상증자/CB 발행 여부, 투자경고 제외    |
+----------------------------------------+------------------------------------------+
                                         |
                                         v
+-----------------------------------------------------------------------------------+
|                    Overnight Order Engine (Go Runtime / KIS API)                  |
+-----------------------------------------------------------------------------------+
|  15:15 Score 계산 -> 15:20 종가 분할/동시호가 매수 -> 익일 09:00 시가/분할 매도   |
+-----------------------------------------------------------------------------------+
```

### 2.1 캔들 및 거래대금 데이터 (Candle & Volume)
* **1차 필터링**: 당일 누적 거래대금 **>= 500억 원** (코스닥), **>= 1,000억 원** (코스피).
* **일봉 캔들 패턴**:
  * **종가 고가형 양봉**: (종가 - 시가) / (고가 - 저가) >= 0.85 (윗꼬리가 짧고 종가가 고가 부근 마감).
  * **돌파 패턴**: 전고점(전일 고가 또는 최근 20일 고가)을 거래량과 함께 돌파.
* **분봉(15분/5분/1분) 패턴 (14:30 ~ 15:20)**:
  * 장 막판 지지력: 14:30 이후 저점을 깨지 않고 우상향 횡보.
  * 동시호가 직전 수급: 15시 15분 ~ 15시 20분 매수 체결강도 및 호가창 매수 잔량 유지.

### 2.2 뉴스 데이터 (News NLP via Gemini 3.0 Flash)
* **Gemini 3.0 Flash 활용**:
  * 뉴스 제목 및 요약을 입력받아 **[신선도, 호재 강도, 테마 연관성]**을 1~10점으로 정량 평가.
  * **키워드 가중치**: "단독", "세계 최초", "정부 정책", "대기업 공급계약", "FDA 승인/임상3상", "AI/반도체/휴머노이드".
  * **타임스탬프 가중치**: 14시 00분 ~ 15시 20분 사이에 처음 발행된 뉴스에 최고 가중치 부여.

### 2.3 DART 공시 데이터 (DART Filings)
* **긍정적 알파 공시 (Score +)**:
  * 단일판매·공급계약 체결 (최근 매출액 대비 **10% 이상**).
  * 제3자배정 유상증자 (납입자가 대기업 또는 대형 사모펀드인 경우).
  * 무상증자 결정, 타법인 주식 및 출자증권 취득.
* **블랙리스트/위험 공시 (즉시 제외)**:
  * 주주배정 유상증자, 전환사채(CB)/신주인수권부사채(BW) 발행, 감자, 배임·횡령, 영업정지.

### 2.4 테마 데이터 (Judal Themes)
* **테마 등수 계산**: 당일 상승 종목 비율 및 테마 내 상위 3개 종목의 평균 상승률 추정.
* **대장주 판별 (Leader Identification)**:
  * 테마 내 **상한가 달성** 또는 **거래대금 1위** 종목을 대장주(Leader)로 선정.
  * 종가 베팅은 **반드시 테마 1등주(대장주)** 또는 **2등주**에 한정하여 집행 (3등 이하 소외주 제외).

### 2.5 펀더멘털 및 매크로 (Fundamentals & Macro)
* **리스크 필터**: 관리종목, 투자경고/투자위험 지정 종목, 시가총액 500억 미만 제외.
* **USD/KRW Watcher 연동**: 장 막판 원/달러 환율 급등(15시 기준 전일 대비 +1.0% 이상) 시 overnight 포지션 비중을 50% 감축.

## 3. Overnight 다중 요소 스코어링 모델 (Scoring Model)

총점 100점 만점 기준으로 점수를 산출합니다.

| 평가 항목 | 세부 지표 | 배점 | Pass/Fail 조건 |
| :--- | :--- | :--- | :--- |
| **1. 기술적 & 수급** | 거래대금 > 500억, 종가/고가 비율 > 90%, 15시 외인·기관 순매수 | **35점** | 거래대금 < 300억 시 자동 탈락 |
| **2. 테마 주도력** | 당일 주도 테마 Top 3 이내, 테마 내 대장주/부대장주 여부 | **25점** | 테마 3등주 이하 탈락 |
| **3. 재료 (뉴스/공시)**| Gemini 3.0 Flash 호재 점수, 장 막판 공시/뉴스 신선도 | **25점** | 악재 뉴스 발생 시 탈락 |
| **4. 리스크 & 매크로** | 펀더멘털 안전성, 환율 변동성, 악재 공시 여부 | **15점** | 유상증자/CB 공시 시 탈락 |

* **진입 조건**: **합산 점수 >= 80점** 이상인 상위 2~3개 종목에 균등 비중 매수.

## 4. 매매 실행 알고리즘 (Trading Execution & Lifecycle)

```
[15:10] Universe Filtering (거래대금, 캔들 조건)
   |
[15:15] Data Processing (News, DART, Theme, USD/KRW Scoring)
   |
[15:20] Final Scoring (80점 이상 종목 Target 선정)
   |
[15:20 ~ 15:30] Entry Execution (동시호가 또는 15:20 지정가 분할 매수)
   |
[09:00 ~ 09:10 익일] Exit Execution (시가 동시호가 매도 또는 09:05 갭상승 익절)
```

1. **매수 타점 (Entry)**:
   * **15시 20분**: 타겟 종목 확정 후 15시 20분 ~ 15시 30분 동시호가에 종가 매수 주문 집행.
2. **청산 타점 (Exit)**:
   * **기본 전략**: 익일 09시 00분 시가 동시호가 매도 (+1% ~ +3% 갭상승 수익 확정).
   * **추세 보유 옵션**: 시가 갭이 +3% 이상 높게 시작하고 1분봉상 거래량이 터지며 상승 시 50% 익절 후 나머지 50%는 09시 10분 트레일링 스탑 적용.
   * **손절 규칙**: 익일 시가 갭하락(-2% 이하) 시 개장 즉시 손절.

## 5. 백테스트 및 검증 방안 (Validation Protocol)

* **Look-ahead Bias 엄격 배제**: 15:20 시점까지 수집된 데이터(뉴스, 캔들, 공시)만 스코어링 모델에 입력.
* **슬리피지 및 수수료 반영**:
  * 매수/매도 수수료 + 증권거래세(약 0.20%) 포함 총 **0.25% 거래 비용** 차감 후 알파 평가.
* **목표 성과 지표**:
  * **승률 (Win Rate)** >= 65%
  * **Profit Factor** >= 1.8
  * **월간 Sharpe Ratio** >= 2.0
